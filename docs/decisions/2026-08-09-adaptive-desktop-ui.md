# 桌面界面自适应与交互规范

状态：已确认并已实施。本文记录主应用和快捷窗口的长期界面规则，不改变业务流程、
IPC、数据库或归档语义。

## 目标

Scene Vault 需要在 Windows 常见桌面尺寸和高缩放比例下保持清晰、紧凑且可操作。
界面延续现有的技术感与轻微发光效果，同时统一信息层级、控件尺寸、键盘操作和
明暗主题表现。

## 尺寸与应用框架

- 最小支持的逻辑窗口为 `1080 × 720`。
- `1440px` 是宽屏布局阈值；达到该宽度时显示完整侧栏，低于该宽度时仅显示图标侧栏。
- 页面标题由内容区统一承担，不再保留重复的全局页头。
- 紧凑侧栏必须为图标提供可见提示和辅助技术标签。
- 页面不得依赖横向滚动完成主要操作。

## 页面布局

- 首页以项目为第一层级。点击卡片主体进入项目，卡片底部只保留“继续捕获”和更多菜单。
- 捕获页以截图预览为主。宽屏常驻人物标记区，窄屏选择截图后自动打开右侧抽屉。
- 人物工作台和历史页在宽屏常驻详情，窄屏使用右侧抽屉；关闭抽屉不清除当前选择。
- 设置页使用左侧分类导航。各分类表单保持挂载，切换分类不得丢失未保存输入。
- 设置存在未保存修改时，离开路由或关闭窗口必须提示用户确认。

## 对话框与快捷窗口

- 模态对话框使用统一的语义化 Dialog 结构，包含标题、说明、遮罩和键盘焦点约束。
- 打开对话框或详情抽屉后，焦点进入浮层；关闭后回到原触发控件。
- `Escape` 可关闭允许取消的浮层，键盘用户能够遍历所有主要操作。
- 分类、笔记和组合快捷窗口统一标题栏、按钮高度、输入焦点和辅助文字可读性。
- 快捷窗口继续保留拖动、置顶、折叠、自动保存和快捷键等既有行为。

## 视觉与语言

- 正文与辅助文字使用现有语义颜色变量，不用颜色单独表达状态。
- 明暗主题都必须保持文本、边框、焦点环和状态色的可辨识度。
- 动效保持克制，并尊重减少动态效果的系统偏好。
- 操作文本使用中文；`Scene Vault` 品牌名以及 Python、ArcFace、Markdown 等必要技术名词
  可以保留英文。

## 验收标准

- 在 `1080 × 720` 和 `1440 × 900` 逻辑窗口下检查首页、捕获、人物工作台、历史和设置。
- 在 Windows 200% 显示缩放下确认内容不被截断，主要操作不依赖横向滚动。
- 使用键盘验证导航、菜单、对话框、抽屉、焦点进入与焦点恢复。
- 明暗主题均检查主要页面、错误状态、禁用状态和焦点状态。
- 前端组件测试、类型检查和生产构建全部通过。

## 非目标

- 本轮不修改 API、数据库迁移、识别算法、归档规则或捕获状态机。
- 不引入新的 UI 框架或视觉依赖。
- 不把界面扩展到手机尺寸，也不新增与现有工作流无关的功能。
