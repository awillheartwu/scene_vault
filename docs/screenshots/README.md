# 界面截图清单

把截图保存为本目录下的 PNG（建议 1440×900 窗口或应用实际窗口尺寸，命名必须一致）：

| 文件 | 内容 | 建议构图 |
|---|---|---|
| `home.png` | 项目总览（Home） | 应用首页，能看到项目卡片与统计 |
| `capture.png` | 捕获页（Capture） | 会话控制、截图条带、处理进度可见 |
| `workbench.png` | 人物工作台（Workbench） | 角色网格 + 选中截图详情（建议确认区） |
| `settings-data-safety.png` | 设置 → 资源与存储 → 数据安全 | 体检/备份/恢复/索引维护卡片 |
| `settings-vision.png` | 设置 → 视觉引擎 | 含“内置引擎（bundled sidecar）已就绪”横幅 |
| `history.png` | 历史页（History） | 筛选栏 + 分页列表 |

注意事项：

- 建议使用不含敏感内容的示例项目截图（避免暴露私人游戏内容/个人信息），确保
  README 可对外公开；
- 用 Win+Shift+S 截图后另存为对应文件名即可；尺寸无硬性要求，清晰即可。
