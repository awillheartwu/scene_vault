# Scene Vault Release Notes

## 1.0.19 — 2026-10-13

本轮收尾：前端 385 项、Windows Rust 348 项回归通过；Python 全量 144 项
中 143 项通过，剩余跨进程 SFace 一致性检查使用已验证的临时图片副本单独补跑通过，
真实 YuNet 加载也已覆盖。Clippy 严格检查、Rust 格式、UTF-8、PowerShell 语法及无
build 发布预检通过，真实数据库 35 条已应用迁移的校验和全部匹配。
2026-10-13 用户确认本轮 Windows 实机验收完成，IC 导入复测也已通过；交付版本统一
为 1.0.19，标准包包含仅应用和内置 AI 两种 NSIS 安装包。

- **发布资源补齐**：随包提供得意黑字体的完整 OFL 许可证；GitHub Release 使用本文件
  说明本轮功能、修复与验证结果。

- **Windows 恢复回滚修复**：还原数据库被迁移校验拒绝时，显式关闭迁移连接后再恢复
  旧数据库；备份、校验和恢复相关的临时 SQLite 连接也等待释放文件句柄，避免 Windows
  文件替换报“拒绝访问”。迁移校验、原图保护和旧数据库恢复规则保持完整。
- **收尾回归整理**：更新后台并行度、Windows 路径和弹窗队列的过时夹具与断言；补充
  IC 忽略内容、迟到监听清理、旧弹窗响应、自动关闭设置、性能日志失败及采样取消回归。
  捕获页事件夹具支持同名事件的多个订阅者，保留替换内容不能沿用旧图片信息的检查。
- **已有截图导入修复**：候选列表排除项目内已移除并忽略的内容，导入时再次检查，
  旧列表中的忽略项不会中断其余图片登记；仍保留移除保护和真实错误提示。IPC 失败日志
  补充实际错误原因，便于后续诊断。2026-10-13 用户反馈 IC 项目导入复测通过。
- **后台处理并行度统一**：取消缩略图最高四路的额外上限，Python 处理、缩略图并发和
  Rust 图片编码统一使用通用设置，选项更名为“后台处理并行度”并说明控制范围。本机
  开发构建与打包工具使用 CPU 0–9（`0x3FF`）；dev 应用启动时恢复系统 CPU 范围，
  后台处理与 release 使用相同设置。启动入口不再固定 Rayon/Tokio 为四线程；Cargo
  job 数保留原有编译内存预算。
- **性能打点补全**：增加前端图片解码/显示就绪、归档准备/复制/校验/重命名与整次保存
  耗时，区分成功、失败和取消。后台每 60 秒采样应用进程资源，每 5 分钟核对自有缓存
  和数据库体积，随性能日志开关停止采样与写入；分析脚本可统一汇总加载、保存、AI
  和资源数据。后续 release 性能分析与优化加入路线图。
- **弹窗与捕获页生命周期修复**：事件监听在注册完成后立即纳入卸载清理，迟到注册会
  立即取消，已卸载组件不再接收回调；同一规则覆盖工作台、笔记面板和处理进度。
  分类弹窗的加载与队列刷新共用请求代次，旧响应不会覆盖新队列；自动关闭在执行前
  重新确认组件、设置和空队列状态，切换到笔记面板后不会被旧分类请求关闭窗口。
- **自动隐藏 UI 截图**：增加全局默认、项目继承/覆盖和逐游戏覆盖，保留旧设置行为。
  插件 1.1.7 修正 Ren'Py 回滚类型导致截图按键表漏挂接，并支持 WIAB 的 URM 控件层；
  游戏内失败提示使用英文。更新并重启一次后，后续设置
  在下一次截图生效。沿用原截图键，冻结元数据后在临时上下文中隐藏标准剧情 UI、重绘
  并同步保存，再恢复原交互；不支持的界面不保存，提示手动 H 后 S。转场与自定义动作
  受保护，失败或保存结果不明不自动重复截图，补齐入口与保存日志。
- **菜单悬停反馈**：右键菜单的可用项增加悬停高亮，与键盘焦点共用同一高亮；禁用项
  不参与高亮，危险项保留红色反馈。
- **Ren'Py 7 版本补全**：支持旧版本 tuple 与数字修订号；旧安装记录可在首页读取时
  补全空版本，多版本项目显示 Ren'Py 7/8。
- **归档编码清理**：撤回有损 WebP 选项和额外编码依赖，保留无损 WebP。旧的有损
  WebP 设置通过新迁移切换为无损 WebP，已有归档文件与其实际质量记录保持不变。
- **工作台项目选择**：选框宽度跟随捕获页同一响应式规格，下拉与其同宽；窄窗口动作可换行，
  避免长项目名被短选框挤压。

- **预览闪烁修复**：捕获页和分类弹框共用图片身份与解码管理，识别、框选状态更新不再
  清空原预览；新图解码后才显示，换图后的迟响应不会回填。空图显示加载或错误提示，
  不再露出破图文字和残留主脸框，也不能提交选区。
- **Ren'Py 引擎适配（可选）**：添加截图来源目录时自动检测游戏并安装插件；一个项目可
  同时安装多个游戏，卸载逐条进行（只删除能证明是本插件写出的文件）；游戏更新移除插件
  后，按钮会提示重新安装。
- **引擎元数据与说话人建议**：截图时把说话人、对话、可见 tag 和虚拟/物理分辨率写进
  应用缓存，入库后立即读取并删除，游戏目录不留文件；捕获详情直接显示这些信息（动态
  角色名会解析为实际显示名）。说话人精确匹配到已有角色时给出建议，视觉匹配为主、
  说话人为辅；两边指向同一角色时标注「说话人匹配」并自动选中；说话人还没有角色时，
  捕获页和分类弹框都可以一键创建角色并直接选中。
- **建议与状态修复**：角色改名后按当前名称和别名实时匹配，不再按旧记录推荐；换图
  不再继承上一张的自动选中；异步创建角色的结果不会串到其他图或项目；保存归档尺寸后
  迟到的读取不再回填旧值。
- **归档输出尺寸**：全局默认 + 项目继承或覆盖，作用于原图直存副本、标注图和头像
  （PNG/JPEG，永不放大）。
- **归档规格扩展为三件套**：尺寸新增「按游戏设定尺寸」（跟随该截图所在游戏的引擎
  设定分辨率），格式可选 保持原格式 / PNG / JPEG / WebP（无损），JPEG 质量 60–100
  可调；三者都是全局默认 + 单项目继承或覆盖，尺寸与格式独立生效（保持原尺寸也能转换
  格式），永不放大，JPEG 的透明部分合成白底。实际使用的参数会随归档记录。
- **归档规格修复与布局**：转换后的文件后缀与 MIME 跟随实际格式；显式 JPEG 与无损
  WebP 即使源格式相同也应用编码规则。捕获页归档标题行显示有效规格，下一行显示目录，
  「调整…」集中编辑三项设置；保存期间禁用控件，会话运行中可查看但不可修改。
- **图片信息记录与展示**：原图与归档图的分辨率、格式、大小（归档图另有实际质量参数）
  在登记与归档时写入数据库，并显示在捕获页、工作台「定位文件」、历史列表与详情和分类
  弹框；只有本应用编码过的文件才显示质量参数，旧归档或已确认被外部替换的文件不沿用
  旧质量参数。捕获页信息接在文件名和时间后面，弹框放在「待分类截图」同行，空间
  不足才换行；不显示对话文本（对话仍入库），普通截图也显示分辨率。
  历史列表固定两行尺寸与状态列；工作台原图/归档图规格和定位按钮对齐。同图更新与迟到
  引擎元数据触发信息刷新，单张和批量读取共用文件有效性过滤，替换文件不写入旧图信息。
- **图片身份与状态刷新**：主动项目/会话检查核对已记录的主归档与头像指纹，识别同大小
  内容替换；原图从缺失/替换恢复时先核对内容，再补回规格。已确认新内容不被旧会话基线
  过滤；直接归档 IPC 同样校验源图。文件检查、恢复和删除部分失败后刷新相关页面。删除
  前核对已有归档指纹，拒绝删除替换内容；拒绝 NAS 永久删除时不恢复失效信息。
- **Ren'Py 版本标识**：安装插件时从 `renpy/vc_version.py` 读取精确版本，插件 1.1.4
  起还会随截图上报运行中的引擎版本；首页项目卡片/列表显示 `Ren'Py 7` / `Ren'Py 8` /
  `Ren'Py 7/8`；未知版本显示 `Ren'Py`。捕获页、工作台与历史页在项目选择框和下拉选项
  的项目名前显示汇总版本，长名称省略并提供完整提示。项目下拉背景不透明、与选择框同宽，
  最多 320px 高，项目较多时在选项区滚动。分类弹框顶栏依次为 Scene Vault、
  项目角标和项目名。首页角标位于卡片封面或列表项目名旁。
- **捕获顶部收紧**：项目栏加宽，来源栏只显示首个目录；多来源以「…」提示，点击弹框
  查看和管理全部目录。归档栏移除常驻继承提示，AI 已配置按配置状态显示绿色。
- **capture-output 缓存清理**：超过体积上限（默认 2 GB）时清理已归档且超过保留期的
  本地中间产物；阈值和保留天数可在设置中调整或关闭。
- **性能日志独立文件**：图片读取、归档缩放、扫描和 AI 请求耗时写入 `logs/perf/`，
  不再进入调试日志面板；日志策略里可一键关闭（打点代码保留）。
- **启动游戏**：首页项目卡片/列表和捕获页都能直接拉起游戏；优先选与游戏目录同名的
  可执行文件，有多个候选时列出让用户选择；只拉起进程，不注入、不等待。
